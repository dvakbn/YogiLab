# YogiLab × Sadhanapada rebuild

This rebuild keeps the original YogiLab content/data/logic and its top splash + atmosphere animation, while replacing the app presentation layer with a Sadhanapada-inspired mobile-first card system.

## Navigation
- Main YogiLab content cards open as full-page detail views.
- Settings is a landing page of separate cards.
- Each Settings card opens its own dedicated page; the Back control returns to Settings first, then to Home.

## Theme
- Light, Dark, and Auto theme continue to use YogiLab's existing theme controls.
- The app-body/card presentation uses Sadhanapada's earthy palette and Marcellus + Mulish typography.

## Top animation
The original YogiLab splash and continuous atmosphere header markup/CSS/JavaScript are retained.
