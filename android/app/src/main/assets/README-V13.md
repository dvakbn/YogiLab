YogiLab V13 change: added exactly one daily reminder time and one weekly reminder time (with existing weekly day selector). Reminder times are stored locally. Notification permission is requested only when the user changes a reminder setting; when the app is open, the app checks the configured times and shows an in-app reminder plus a browser notification where permitted. Existing Google Calendar and ICS tools now use the configured weekly reminder time. No other app behavior was intentionally changed.
